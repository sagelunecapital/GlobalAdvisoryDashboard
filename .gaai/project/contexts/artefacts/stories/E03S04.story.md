# Story E03S04: Display Macro Module

## User Story

**As a** fund manager,
**I want** to see all 32 macro indicators in a single organized view with their current value, weekly change, standard deviation, z-score, and any active signal alerts with explanations,
**so that** I can scan the macro landscape in seconds and immediately identify stress points without opening multiple data terminals.

---

## Context

The Macro module display is a structured table or card layout organized by the five indicator categories: Inflation, Yields, Currencies, Futures, Growth. Each indicator row shows: current value, week-over-week % change, rolling standard deviation, and current z-score. Rows with active 2σ signals are visually highlighted and include the natural-language reason from E03S03, displayed inline (always visible without hover). The display reads all metrics from the pre-computed series in the database — no computation occurs in the display layer.

---

## Acceptance Criteria

- [ ] AC1: Given all macro data is available, the display renders 32 indicator rows grouped into five labelled sections: Inflation (7 rows), Yields (7 rows), Currencies (7 rows), Futures (5 rows), Growth (6 rows)
- [ ] AC2: Each indicator row displays: (a) indicator name, (b) current value with appropriate unit (%, bps, USD, etc.), (c) week-over-week % change with sign and direction arrow or color, (d) 52-week rolling standard deviation value, (e) current z-score displayed as a signed numeric value (e.g., "+2.3σ" or "−1.4σ") — the z-score provides deviation magnitude context that the std dev alone cannot convey
- [ ] AC3: Given an indicator has an active 2σ signal, its row is visually highlighted (distinct background color, badge, or border) and the natural-language alert reason from E03S03 is displayed inline below the row — always visible without requiring a hover or click interaction
- [ ] AC4: Given no indicators have active 2σ signals, the display renders all rows without highlights and shows a summary message (e.g., "No macro signals active") at the top of the module
- [ ] AC5 (data-freshness): The display shows the date of the most recent data used for each category or at module level — the fund manager can confirm data is not stale
- [ ] AC6 (error-handling): Given one or more indicators failed to load or compute, the affected row(s) display a visible placeholder (e.g., "Data unavailable") — the remaining rows render normally with their data
- [ ] AC7 (error-handling): Given all data fails to load, the module renders an explicit error state rather than an empty layout
- [ ] AC8 (signal-detection): Given an indicator has z-score ≥ 2 or ≤ −2, its row is highlighted and the inline alert reason is shown; given z-score between −2 and +2 (exclusive), the row is not highlighted and no reason text is displayed — no false-positive highlights are generated for within-range indicators

---

## Out of Scope

- Historical charting of individual indicators (current values only — no time-series chart per indicator)
- User-configurable alert thresholds or indicator selection
- Exporting or downloading indicator data
- Push notifications or email alerts

---

## Dependencies

- E03S03 — signal detection and natural-language reasons must be computed before display can read them

---

## Notes

Delivery chooses the visual presentation (table, card grid, or hybrid). The key constraint is that all 32 indicators are visible in a single view without requiring horizontal scrolling on a standard desktop browser. Signal-highlighted rows must be immediately noticeable without relying solely on color (consider icons or badges for accessibility). Units should be displayed consistently: yields and rates in %, spreads in basis points (bps), currencies as price ratios, futures in USD per unit, PMI as index value.
