# Story: Preview and open an industry's charts from a Leadership-tab chip

## User Story

**As a** fund manager reading the Leadership tab,
**I want** to preview an industry's constituent charts on hover and open the full set in one action,
**so that** I can visually confirm an industry's momentum without leaving the dashboard or re-typing tickers.

---

## Context

Each Leadership-tab industry chip already lists the industry's constituent tickers. Today there is no way to see those names charted without leaving the dashboard, opening a charting tool, and manually entering the tickers. This story adds a quick-glance chart preview on hover and a one-action path to the full charted set, reusing the industry-to-ticker mapping the Leadership tab already holds.

A key constraint discovered during Discovery: the external charting tool's full pages cannot be embedded inline (the provider blocks framing from other sites), but its individual ticker charts can be displayed directly. The preview is therefore built from individual ticker charts, while the full-set view opens in the external tool itself.

---

## Acceptance Criteria

- [ ] AC1: Given an industry chip on the Leadership tab that has one or more tickers, when the manager hovers over the chip, then a preview appears showing candlestick charts for that industry's tickers.
- [ ] AC2: Given the preview is showing, when the manager moves the pointer away from the chip (and away from the preview), then the preview is dismissed.
- [ ] AC3: Given an industry with more tickers than the preview displays, when the preview appears, then it shows a bounded number of charts and clearly indicates how many additional tickers are not shown (e.g. a "+N more" indicator).
- [ ] AC4: Given an industry chip, when the manager activates it (click), then the external charting tool opens in a new browser tab showing the charted/screener (candlestick) view of exactly that industry's tickers, requiring no manual ticker entry.
- [ ] AC5: Given the chip's tickers, when the full-set view is opened, then the tickers passed to the external tool match the industry's current ticker list (same membership, correctly delimited/encoded) and no other tickers.
- [ ] AC6: Given the largest industries carry well over 100 tickers, when the manager opens the full-set view for such an industry, then the charted view still opens successfully with that industry's tickers (the open path must remain functional at the maximum ticker count, not silently truncate or fail).
- [ ] AC7 (error-handling): Given an industry chip with an empty ticker list, when the manager hovers or activates it, then no broken preview and no malformed full-set view is produced — the chip behaves benignly (e.g. no preview, or a clear "no tickers" state).
- [ ] AC8 (error-handling): Given an individual chart that fails to load within the preview, when the preview is shown, then the failed chart does not break the preview layout or block the remaining charts from displaying.
- [ ] AC9: Given the new hover/preview/open behavior is added, when the Leadership tab is used as before (tier columns, chip ordering, ticker labels, edit controls), then existing Leadership-tab behavior is unchanged.
- [ ] AC10: Given this feature is additive client-side behavior in the dashboard page, when it is implemented, then it must not alter or interfere with the dashboard's data-injection block governed by DEC-2026-04-27-01 (no changes to the injected DATA BLOCK markers or to `update_dashboard.py`).

---

## Out of Scope

- Reclassifying tickers between industries, or editing `sector_rotation.json` / industry membership.
- Changing leadership tier assignments or the leadership snapshot data.
- Any tab other than Leadership.
- Caching, proxying, or storing chart images on the dashboard's own infrastructure.
- Configurable preview size or chart style as a user setting (a fixed, sensible default is sufficient).

---

## Dependencies

- None. Builds on the existing Leadership tab and its industry-to-ticker mapping.

---

## Notes

- **Constraint (verified during Discovery):** the external charting provider blocks cross-site framing of its full pages, so the inline preview must be composed of individual ticker charts rendered directly; the full-set view opens in the provider's own tab. Delivery must not attempt to iframe/embed the provider's screener page.
- **Risk:** displaying the provider's chart images directly is adjacent to the provider's terms of use. This is a flagged risk, not a blocker — surface it, do not silently design around it.
- **Performance:** the largest industries carry well over 100 tickers; the preview must be bounded (AC3) and should avoid loading charts that are not displayed.
- **Non-interference:** this is additive client-side behavior in the dashboard page; it must not disturb the data-injection mechanism governed by DEC-2026-04-27-01.
- Delivery owns all implementation specifics (preview cap value, chart parameters, exact URL format, hover vs. focus mechanics, lazy-loading approach).
