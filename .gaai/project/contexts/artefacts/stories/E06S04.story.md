# Story E06S04: Implement /api/liquidity Live Endpoint

## User Story

**As a** fund manager,
**I want** the dashboard's liquidity panel to show the current net liquidity reading fetched live from FRED,
**so that** I can assess the liquidity backdrop from real-time data on every page load.

---

## Context

Net liquidity is computed from three Federal Reserve balance sheet components: total assets (WALCL), Treasury General Account (WDTGAL), and overnight reverse repurchase agreements (WLRRAL). The canonical formula is `net_liquidity = WALCL − WDTGAL − WLRRAL` (E02S02). IORB is NOT a component of this formula. All three series are available as weekly FRED releases. This endpoint fetches the three series, computes net liquidity, and returns the current value and WoW% change.

---

## Acceptance Criteria

- [ ] AC1: `GET /api/liquidity` fetches exactly three FRED series: `WALCL` (Fed total assets), `WDTGAL` (Treasury General Account), `WLRRAL` (overnight RRP); `FRED_API_KEY` read from environment; `observation_start` set to 30 days before today for all three series; no other FRED series are fetched
- [ ] AC2: `net_liquidity` computed as `WALCL − WDTGAL − WLRRAL` on the intersection of dates where all three series have a non-null value; the computation date is the most recent date present in all three series (conservative: `min(latest_date(WALCL), latest_date(WDTGAL), latest_date(WLRRAL))`); WoW% = `(net_liq_latest − net_liq_7d_prior) / abs(net_liq_7d_prior) * 100`, where `net_liq_7d_prior` is the net liquidity computed at the nearest date ≥ 7 calendar days before the computation date
- [ ] AC3: Response JSON schema: `{ "net_liquidity": float, "wow_pct": float, "components": { "WALCL": float, "WDTGAL": float, "WLRRAL": float }, "report_date": "YYYY-MM-DD", "updated_at": "<ISO-8601 UTC>" }`; `report_date` = `min(latest_date(WALCL), latest_date(WDTGAL), latest_date(WLRRAL))` — the most conservative common observation date; `components` values are the individual series values on `report_date`
- [ ] AC4 (error-handling): If any of the three required FRED series fetch fails, returns HTTP 503 with `{ "error": "fred_fetch_failed", "series": "<series_id>", "detail": str }`; net liquidity cannot be computed from partial inputs — no partial response; no silent fallback to a 2-component computation

## Notes

The three-component formula (`WALCL − WDTGAL − WLRRAL`) is the canonical definition from E02S02. IORB appears as a liquidity component in some older references but is excluded from this formula per E02S02.

WoW% lookback: 7 calendar days. FRED weekly series (WALCL, WDTGAL, WLRRAL) update on Thursdays. A 7-day lookback resolves to the prior week's Thursday observation in normal conditions. If no value exists exactly 7 days prior, use the nearest earlier value within 10 calendar days; if none exists, return `wow_pct: null`.

`observation_start` of 30 days provides at least 4 weekly observations for each series — sufficient for the WoW% lookback.
