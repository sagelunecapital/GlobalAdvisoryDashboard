# Story E03S01: Fetch and Persist 32 Macro Indicators

## User Story

**As a** fund manager,
**I want** the dashboard to automatically retrieve and store current and historical values for 32 macro indicators across five categories,
**so that** I have a complete weekly dataset available for analysis and signal detection without manual data collection.

---

## Context

The Macro module monitors 32 indicators grouped into five categories: Inflation (7), Yields (7), Currencies (7), Futures (5), and Growth (6). Primary sources: Barcharts and Yahoo Finance. Authorized secondary source: FRED API (for indicators not available via primary sources, particularly breakeven inflation rates T5YIE and T2YIE). GDPNow is sourced from the Atlanta Federal Reserve Bank — a separate institution from FRED. Frequency is weekly for all series; monthly-released indicators (CPI, Core CPI, PCE, Core PCE, PPI, ISM Manufacturing, ISM Services, NFP, Unemployment Rate, Retail Sales) use the most recently released value as the current weekly observation. History must go back at least 52 weekly observations (or 12 monthly observations for monthly-released indicators) to support rolling standard deviation computation.

**Indicator list:**

Inflation:
- CPI YoY (US Consumer Price Index, year-over-year %)
- Core CPI YoY (ex food and energy, year-over-year %)
- PCE YoY (Personal Consumption Expenditures deflator, year-over-year %)
- Core PCE YoY (ex food and energy, year-over-year %)
- PPI YoY (Producer Price Index, year-over-year %)
- 5-Year Breakeven Inflation Rate
- 2-Year Breakeven Inflation Rate

Yields:
- US 2Y Treasury Yield
- US 5Y Treasury Yield
- US 10Y Treasury Yield
- US 30Y Treasury Yield
- 2s10s Spread (10Y minus 2Y)
- 10Y-3M Treasury Spread
- Effective Federal Funds Rate

Currencies:
- DXY (US Dollar Index)
- EUR/USD
- GBP/USD
- USD/JPY
- AUD/USD
- USD/CNH
- USD/CHF

Futures:
- Gold (continuous front-month)
- Crude Oil WTI (continuous front-month)
- Copper (continuous front-month)
- Natural Gas (continuous front-month)
- Corn (continuous front-month)

Growth:
- GDPNow (Atlanta Fed real-time GDP estimate, current quarter)
- ISM Manufacturing PMI
- ISM Services PMI
- Non-Farm Payrolls (monthly, thousands)
- Unemployment Rate (%)
- Retail Sales MoM (%)

---

## Acceptance Criteria

- [ ] AC1: Given initial setup, the system fetches at least 52 weekly observations (or 12 monthly observations for monthly-released indicators) of historical data for all 32 indicators and persists each as a named series with indicator ID, date, and value
- [ ] AC2: For monthly-released indicators (CPI, Core CPI, PCE, Core PCE, PPI, ISM Manufacturing, ISM Services, NFP, Unemployment Rate, Retail Sales), the most recently released value is stored as the current observation — not forecasted or interpolated
- [ ] AC3: GDPNow is fetched from the Atlanta Federal Reserve Bank GDPNow data page and stored as the current quarter's real-time estimate
- [ ] AC4: For futures indicators (Gold, Crude Oil, Copper, Natural Gas, Corn), the continuous front-month contract price is used
- [ ] AC5: Given a subsequent refresh run, only new observations not yet in the database are fetched and appended — historical data is never overwritten or deleted
- [ ] AC6 (error-handling): Given any individual indicator fetch fails, the system surfaces a visible error identifying the failed indicator(s) — it continues fetching the remaining indicators and stores all successfully retrieved data
- [ ] AC7 (error-handling): Given the GDPNow source is unavailable, the system surfaces a visible error for that indicator only and does not block other indicators from being stored
- [ ] AC8 (data-freshness): Each stored record includes the indicator ID, date, value, and fetch timestamp
- [ ] AC9 (signal-detection): Given all indicator data is fetched and persisted, each series is stored under a consistent named indicator ID (e.g., `US_10Y_YIELD`, `CPI_YOY`) with fields (indicator_id, date, value) sufficient for E03S02 to compute rolling mean and std dev without requiring data format transformation — the storage schema supports direct downstream z-score computation
