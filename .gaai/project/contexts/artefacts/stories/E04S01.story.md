# Story E04S01: Build Single-File HTML Dashboard Prototype with Sample Data

## User Story

**As a** fund manager,
**I want** a self-contained HTML file that shows a representative sample output of the complete dashboard across three tabs (Macro, Breadth, Execution),
**so that** I can review the full information layout and user experience before the live data pipeline is wired up.

---

## Context

The prototype uses hardcoded sample data — it does not connect to any live data source. All data starts from January 2020. The file must open directly from the local filesystem with no server, no build step. The Tableau Public embed in the Breadth tab is the only permitted external network dependency (explicitly requested by the fund manager for the RS factor dashboard).

---

## Acceptance Criteria

### General
- [ ] AC1: Single `.html` file with all CSS and JS embedded; Tableau JS API from `public.tableau.com` is the only permitted external script
- [ ] AC2: Renders correctly from `file://` protocol in any modern browser
- [ ] AC3: Three top-level tabs: **Macro**, **Breadth**, **Execution** — one visible at a time
- [ ] AC4: All SVG charts use a fixed virtual canvas (`viewBox` with `preserveAspectRatio="none"`) so charts in hidden tabs render at correct width when first shown; all charts have equal width across the page
- [ ] AC5: Interactive hover tooltip on every chart showing date and value(s)
- [ ] AC17: Visual theme must comply with `PS Design.md` — PlayStation Blue (`#0070cc`) as primary accent, Inter weight 300 for display headlines ≥22px, card border-radius 12–24px, full-pill (`999px`) buttons with the cyan hover signature (`#1eaedb` fill + 2px white border + 2px blue outer ring + `scale(1.2)` on hover)

### Macro Tab
- [ ] AC6: **Inflation section** — CPI / PCE / PPI outer tabs; Headline / Core sub-tabs within each; each sub-tab shows YoY% chart (top) and MoM% chart (below); all data from Jan 2020
- [ ] AC7: **Yields section** — 3-column grid: (1) Nominal multi-line chart (US01Y, US02Y, US05Y, US10Y, US30Y); (2) Real multi-line chart (DFII5, DFII10, DFII30; 1Y/2Y labeled "to follow"); (3) Inflation Breakeven multi-line (5Y=US05Y−DFII5, 10Y=US10Y−DFII10, 30Y=US30Y−DFII30; 1Y/2Y to follow)
- [ ] AC8: **Spreads section** — 3-column grid below yields: (1) Nominal 10Y−2Y; (2) Real 10Y−5Y; (3) Breakeven 10Y−5Y
- [ ] AC9: Macro section does NOT include Currencies, Futures, or Growth categories
- [ ] AC10: **Liquidity section** — raw series tabs labeled: Reserve Balance, Fed Liquidity, Trade Balance, Bitcoin (no "Section A / Section B" labels); combined YoY% 3MA chart with dual Y-axis (Bitcoin on right axis with symlog scale, dashed line, labeled "RHS (log)")

### Breadth Tab
- [ ] AC11: Tableau Public embed (`Factors_17748612623900/RS`) loaded lazily on tab click; placeholder shown while loading
- [ ] AC12: % Above MA cards (20d, 50d, 200d/MMTH, NYSE A/D) with progress bars
- [ ] AC13: Breadth indicators table (McClellan, Hi/Lo, TRIN, Put/Call, etc.)
- [ ] AC14: NYSE cumulative A/D line chart

### Execution Tab
- [ ] AC15: **Top section** — 2-column equal grid: left = Market Regime card (badge, 4 indicator cards, condition box); right = General Tactics card with editable textarea and Edit/Save button
- [ ] AC16: **Bottom section** — Sector Focus card: "+ New Sector" button prompts for sector name, creates a block with Thesis textarea + Tickers textarea + Delete button; sectors can be deleted individually
