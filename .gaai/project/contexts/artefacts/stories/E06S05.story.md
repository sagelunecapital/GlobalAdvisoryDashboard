# Story E06S05: Implement /api/regime-macro Live Endpoint

## User Story

**As a** fund manager,
**I want** the dashboard's Regime section to show live cross-signal readings (growth, inflation, monetary policy, currency, market narrative) fetched on every page load,
**so that** I can assess the regime-macro picture from current data without running a script.

---

## Context

The regime-macro signals are computed from a set of cross-module data sources. The authoritative implementation is `_regime_macro_block()` in `update_dashboard.py`. This story ports that function to a stateless API endpoint.

Key implementation notes from the source:
- Net liquidity WoW% uses WRESBAL (a single FRED series — the reserve balance proxy), **not** the three-component WALCL/WDTGAL/WLRRAL formula from E06S04. These are two different liquidity metrics serving different analytical purposes.
- WoW% lookback windows match the source code exactly: T5YIE → 5 calendar days; DGS2 → 5 calendar days; DGS10 → 5 calendar days; WRESBAL (net_liq_wow) → 8 calendar days.
- DGS10 is fetched from yfinance `^TNX`, not from FRED `DGS10`.
- FX 5-day % change uses 6th-to-last close as the base (i.e., close[−6] vs close[−1] in a daily series).
- GDPNow staleness is evaluated via the `fetched_at` ISO-8601 field embedded in `prototypes/gdpnow.json`, not filesystem mtime (mtime reflects deploy time in serverless, not content age).

The signal computation logic (scoring, regime label derivation) is defined in E05S02.story.md. This endpoint returns raw values only — no scoring.

## Acceptance Criteria

- [ ] AC1: `GET /api/regime-macro` fetches the following sources: SOFR weekly avg (`FRED SOFR`, `freq=wef`, `aggr=avg`), IORB weekly avg (`FRED IORB`), GDP YoY% (`FRED GDP`, `units=pc1`), T5YIE (`FRED T5YIE`, 14-day window), DGS2 (`FRED DGS2`, 14-day window), DGS10 (yfinance `^TNX`, 14-day daily series), WRESBAL net liquidity proxy (`FRED WRESBAL`, 21-day window), FX 5-day % change for USDJPY (`JPY=X`), USDCNH (`CNH=X` with `CNY=X` fallback on fetch failure), EURCHF (`EURCHF=X`), DXY (`DX-Y.NYB`); all yfinance FX tickers fetched with `period="10d"` to ensure 6+ trading days
- [ ] AC2: GDPNow latest estimate included as `gdpnow` in the response; source priority: (1) `prototypes/gdpnow.json` if present and contains a parseable `fetched_at` ISO-8601 field where `(utcnow − fetched_at) < 48 hours`; (2) FRED `GDPC1` (latest annual GDP observation) as fallback; filesystem mtime must NOT be used for staleness detection
- [ ] AC3: Change computation rules — all lookback windows measured in calendar days; nearest earlier available value used if exact calendar date has no observation:
  - `t5yie_wow`: `(T5YIE_latest − T5YIE_5d_prior) / abs(T5YIE_5d_prior) * 100`
  - `us2y_wow`: `(DGS2_latest − DGS2_5d_prior) / abs(DGS2_5d_prior) * 100`
  - `us10y_wow`: `(^TNX_latest − ^TNX_5d_prior) / abs(^TNX_5d_prior) * 100`
  - `net_liq_wow`: `(WRESBAL_latest − WRESBAL_8d_prior) / abs(WRESBAL_8d_prior) * 100`
  - FX 5-day %: `(close[−1] − close[−6]) / abs(close[−6]) * 100` on the yfinance daily series (6th-to-last close as base)
- [ ] AC4: Response JSON schema exactly matches the `macroRegime` shape consumed by `_regime_macro_block` in `update_dashboard.py`: `{ "gdpnow": float|null, "gdp_yoy": float|null, "t5yie_wow": float|null, "us2y_wow": float|null, "us10y_wow": float|null, "sofr": float|null, "iorb": float|null, "net_liq_wow": float|null, "usdjpy_5d": float|null, "usdcnh_5d": float|null, "eurchf_5d": float|null, "dxy_5d": float|null, "updated": "YYYY-MM-DD" }`; `updated` = date of the most recently fetched data point across all sources; all numeric fields are `null` if fetch or computation failed for that source
- [ ] AC5 (error-handling): Individual source failures return `null` for the affected field(s) — endpoint returns HTTP 200 with partial data; error metadata included as a top-level `"errors"` object: `{ "errors": { "<field_name>": "<error detail>", ... } }`; `"errors"` is omitted or empty if all fetches succeed; HTTP 503 returned only if ALL sources are unreachable: `{ "error": "all_fetches_failed", "detail": str }`

## Notes

`WRESBAL` (reserve balances with Federal Reserve Banks) is the net liquidity proxy used in `_regime_macro_block()`. It is a different metric than the WALCL−WDTGAL−WLRRAL formula in E06S04, which is the canonical net liquidity computation. Both coexist in the dashboard for different analytical purposes — do not merge or substitute them.

The 14-day `observation_start` window for T5YIE, DGS2 and the 21-day window for WRESBAL provide enough history for 5-day and 8-day lookbacks respectively, including weekends and holidays.

USDCNH fallback: attempt `CNH=X` first; if yfinance returns an empty or error DataFrame, retry with `CNY=X`. Log which ticker was used in the response or error metadata.
