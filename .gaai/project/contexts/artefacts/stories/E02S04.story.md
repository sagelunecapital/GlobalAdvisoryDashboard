# Story E02S04: Display Liquidity Module

## User Story

**As a** fund manager,
**I want** to view liquidity indicators in a clear two-section layout — raw series in tabbed charts and YoY% 3MA in separate charts — so that I can assess both the absolute level and the trend of liquidity conditions at a glance.

---

## Context

The Liquidity module display has two sections. Section A shows raw data as tabbed charts: four tabs (WRESBAL, Net Liquidity, BOPGSTB, Bitcoin), one chart per tab, so the user can switch between raw series without overlapping lines. Section B shows three separate YoY% 3MA charts (WRESBAL, Net Liquidity, BOPGSTB) stacked or side-by-side — not overlaid on one chart. Bitcoin has no YoY% 3MA chart. Both sections read from pre-computed series in the database.

---

## Acceptance Criteria

- [ ] AC1: Given all liquidity data is available, Section A renders four tabs labelled "WRESBAL", "Net Liquidity", "Trade Balance (BOPGSTB)", and "Bitcoin" — clicking a tab shows that series' raw time-series chart; only one tab's chart is visible at a time
- [ ] AC2: Each Section A tab chart displays data from 2020-01-01 to the most recent available date at the native frequency of the series: weekly for WRESBAL and Net Liquidity, monthly for BOPGSTB, and weekly for Bitcoin (monthly Bitcoin data is stored per E02S01 but Section A displays the weekly series for consistency with the other weekly series)
- [ ] AC3: Given all liquidity data is available, Section B renders three separate charts: WRESBAL YoY% 3MA, Net Liquidity YoY% 3MA, and Trade Balance YoY% 3MA — each chart is self-contained and labelled clearly
- [ ] AC4: Each Section B chart displays data from the earliest date where a 3MA value is available (approximately one year after 2020-01-01) to the most recent computed date
- [ ] AC5 (data-freshness): Each section displays the date of the most recent data point shown — stale data is never presented without a visible date stamp
- [ ] AC6 (error-handling): Given one or more series failed to load or compute, the affected chart slot displays a visible error placeholder (e.g., "Data unavailable: WRESBAL") rather than an empty or blank chart — the remaining charts render normally
- [ ] AC7 (error-handling): Given all data fails to load, the display renders an explicit module-level error state rather than an empty layout

---

## Out of Scope

- Overlaying multiple raw series on a single chart (each series has its own tab/chart)
- Interactive filtering or date-range selection by the user
- Exporting or downloading chart data
- Alerts or notifications

---

## Dependencies

- E02S03 — YoY% and 3MA series must be computed before display can read them

---

## Notes

Delivery chooses the charting library. Both sections should feel visually consistent. Section A tabs and Section B charts should be clearly labelled with the series name and unit (e.g., "$B" for billions, "%" for YoY%). Delivery may use any layout (vertical stack, grid) for Section B as long as the three charts are individually legible without horizontal scrolling on a standard desktop browser.
