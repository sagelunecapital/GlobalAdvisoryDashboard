# Epic E04: Dashboard HTML Prototype

## Purpose

Fund managers and the development team can see a representative, single-file HTML render of the complete dashboard — Market Regime, Liquidity, and Macro modules together — using sample data, so they can validate the overall UX, layout, and module interaction before the live data pipeline is fully delivered.

---

## Scope

- Single self-contained HTML file with embedded CSS and JavaScript
- Sample/mock data for all three modules: Market Regime (from E01), Liquidity (from E02), Macro (from E03)
- Module-level tab navigation between the three sections
- Faithful to the display specifications from E01S04, E02S04, and E03S04
- No live data, no backend, no external dependencies

---

## Out of Scope

- Live data integration (this is a prototype only)
- User authentication or access control
- Deployment infrastructure
- Mobile-specific layout optimization

---

## Stories

> Stories are tracked in the backlog. This list is descriptive only.

- E04S01: Build single-file HTML dashboard prototype with sample data

---

## Success Metrics

- All three modules visible in a single HTML file navigable by tab
- Sample data populates all display elements faithfully
- No external dependencies — file opens correctly from the local filesystem
- Fund managers can review the layout and confirm the information hierarchy before live delivery

---

## Dependencies

- E01 display stories must be delivered (E01S04) before this prototype is finalized
- E02 display stories must be delivered (E02S04) before this prototype is finalized
- E03 display stories must be delivered (E03S04) before this prototype is finalized
