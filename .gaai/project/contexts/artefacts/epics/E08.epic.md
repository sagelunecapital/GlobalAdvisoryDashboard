# Epic: Leadership Tab — External Chart Integration

## Purpose

On the Leadership tab, a fund manager sees each industry as a chip carrying a list of constituent tickers, but has no way to see how those names actually look on a chart without leaving the dashboard, opening a charting tool, and re-typing the tickers by hand. This breaks the daily decision flow: the manager wants to glance at an industry's price action while reading its momentum tier, and occasionally drill into the full set.

This Epic delivers a direct visual bridge from each Leadership-tab industry to its charts — a quick at-a-glance view on hover, and a one-action path to the complete charted set — so the manager can read momentum and confirm it visually in the same place, without manual ticker entry.

---

## Scope

- A quick-glance chart preview surfaced from a Leadership-tab industry chip, showing the industry's constituent tickers as candlestick charts.
- A one-action path from an industry chip to the full charted set of that industry's tickers in the manager's external charting tool.
- Sensible handling when an industry has many tickers (preview stays usable; full set remains reachable).
- Reuse of the existing industry-to-ticker mapping already present on the Leadership tab.

---

## Out of Scope

- Reclassifying any ticker into a different industry (handled separately, in the sector-classification source).
- Changing the sector-rotation data (`sector_rotation.json`) or the industry membership of any group.
- Changing how industries are assigned to momentum tiers (the leadership snapshot data).
- Any feature on tabs other than Leadership.
- Persisting, caching, or storing chart images on the dashboard's own infrastructure.

## Success Metrics

- From the Leadership tab, the manager can see an industry's constituent charts without manually typing any ticker.
- Hovering an industry chip surfaces a chart preview; the preview remains usable even for the largest industries (no unbounded image load).
- A single action from the chip opens the full set of that industry's charts in the external charting tool, pre-loaded with the correct tickers.
- The feature degrades gracefully: industries with no tickers, and individual charts that fail to load, do not break the Leadership tab.

---

## Dependencies

- None (sequencing). The feature builds only on the Leadership tab and its existing industry-to-ticker mapping, both already present.
- Constraint (non-sequencing): must not disturb the existing dashboard data-injection mechanism governed by DEC-2026-04-27-01 — this feature is additive client-side behavior only.
